Acerca del Proyecto

Plataforma educativa desarrollada para el curso de Programación IV.

Objetivo del sitio

Este proyecto fue desarrollado como parte del curso de Programación IV de la Universidad Nacional de Costa Rica, con el propósito de aplicar conocimientos relacionados con el desarrollo web moderno.

La plataforma funciona como un entorno educativo interactivo, donde los estudiantes pueden consultar contenido teórico, visualizar ejemplos prácticos y reforzar conocimientos mediante cuestionarios y actividades dinámicas.

Además, busca servir como una base para futuras mejoras relacionadas con frontend, backend y experiencias de usuario.

Contenido Académico

El sitio incorpora distintos temas fundamentales relacionados con el desarrollo web y tecnologías modernas.

  • Fundamentos de Internet y la Web.
  • HTML y estructura de documentos.
  • CSS y estilos responsivos.
  • JavaScript e interactividad.
  • Conceptos básicos de backend.
  • Spring Boot y aplicaciones web.

Cada sección incluye explicaciones, ejemplos prácticos y cuestionarios básicos para reforzar el aprendizaje.

Tecnologías Utilizadas

El proyecto fue desarrollado utilizando herramientas y tecnologías modernas enfocadas en el desarrollo web.

HTML5 CSS3 JavaScript Bootstrap 5 Spring Boot IntelliJ IDEA

Bootstrap fue utilizado para construir una interfaz responsive y moderna, mientras que JavaScript permite manejar la interacción dinámica de los usuarios.

El backend está orientado a Spring Boot, facilitando la creación de aplicaciones robustas basadas en Java.
